# 한눈에 보기

> 2026-10-27 기준 · 처음 보는 분이 5분 안에 서비스·구조·현재 상태를 파악하도록 만든 한 장입니다. 자세한 내용은 아래 "문서 지도"의 링크로.

## 1. 무엇을 만드나

**외식업 사장님용 AI 노출 진단 서비스.** 손님이 "망원동 돈까스 맛집"을 ChatGPT·Gemini에 물을 때, AI가 우리 가게를 말해 주는지 진단하고 개선 방법을 제안합니다.

| 단계 | 하는 일 |
| --- | --- |
| 입력 | 상호 · 지역(동) · 대표 메뉴 (+ 가까운 역, 이메일은 선택·동의 시) |
| 진단 | 손님 질문 10개를 Gemini(웹 검색)에 3번씩 → 답변 30개에서 우리 가게 언급률 계산 |
| AI Agent | 언급률 30% 미만이면 자동, 아니면 "더 자세히 진단하기" 버튼 → AI가 질문 도구 3개 중 골라 원인을 좁힘 |
| 결과 | 화면에 언급률·질문 유형별 결과·함께 나온 가게·추가 진단·개선 제안 3개 / Make가 메일 발송 + 구글 시트 기록 |

## 2. 바로 써 보기

- 주소: https://codyssey-final-geo.vercel.app/ (로그인 없음, 진단 약 20~35초)
- Agent 자동 실행 확인: 상호 `초록별돈까스 망원점` · 지역 `서울 마포구 망원동` · 메뉴 `등심돈까스` (실존하지 않는 이름 → 언급률 0%)
- 버튼 확인: 상호 `명동교자` · 지역 `서울 중구 명동` · 메뉴 `칼국수, 만두` → "더 자세히 진단하기"

## 3. 구조

```
사장님 화면 (geo_frontend · React)
   │ POST /api/diagnose, /api/more
   ▼
서버 (api/ · Vercel Python 함수) ── 웹훅 ──▶ Make ──▶ 구글 시트 + Gmail
   │ run_diagnosis / run_more
   ▼
AI 진단 (ai/) ──▶ Gemini API (웹 검색, 함수 호출로 Agent 도구 선택)
```

| 기술 요소 (평가 G3) | 어디에 |
| --- | --- |
| AI Agent | `ai/agent.py` 질문 도구 3개 → `ai/gemini_client.py` `choose_tools()` (Gemini 함수 호출) |
| 자동화 워크플로우 | `server/make_sender.py` → Make (웹훅 → 시트 → 동의 시 연락처 시트 + Gmail) |
