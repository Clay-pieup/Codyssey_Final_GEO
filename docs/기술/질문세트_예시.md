# 외식업 질문 세트 설계 예시

> **가상의 가게로 만든 예시입니다.** 지역 이름은 실제, 가게 이름은 가상입니다.
> [질문세트_측정기준.md](질문세트_측정기준.md) 2·3장 규칙이 업종과 입력 조건이 달라도 그대로 적용되는지 보여 주는 자료입니다.
> 실제 생성은 AI가 하므로 문장은 매번 조금씩 달라지고, 유형별 개수와 규칙은 같게 유지됩니다.

## 0. 행복돈까스 (기준 예시)

| 입력 | 값 |
| --- | --- |
| 지역 | 서울 마포구 망원동 → 동: 망원동 |
| 가까운 역 | 망원역 |
| 대표 메뉴 | 등심돈까스, 치즈돈까스 |

- 질문 10개는 [질문세트_측정기준.md](질문세트_측정기준.md) 3-3 참고

## 1. 소문난화로 (고깃집)

| 입력 | 값 |
| --- | --- |
| 지역 | 서울 영등포구 문래동 → 동: 문래동 |
| 가까운 역 | 문래역 |
| 대표 메뉴 | 숙성 삼겹살, 목살 |

**상황·조건 선택**
- 상황: 회식·단체 / 친구 모임 / 가족 외식 → 고깃집은 여럿이 가는 업종
- 조건: 가성비(고정) / 예약 가능 → 단체 손님은 예약 여부를 먼저 물음

| id | 유형 | 질문 |
| --- | --- | --- |
| q1 | 지역 일반형 | 문래동 맛집 추천해줘 |
| q2 | 지역 일반형 | 문래역 근처 저녁 먹을 데 있어? |
| q3 | 메뉴형 | 문래동 숙성 삼겹살 맛집 |
| q4 | 메뉴형 | 문래역 목살 맛있는 고깃집 |
| q5 | 메뉴형 | 문래동 고깃집 추천해줘 |
| q6 | 상황형 | 문래역 회식하기 좋은 곳 |
| q7 | 상황형 | 문래동 친구들이랑 고기 먹을 곳 |
| q8 | 상황형 | 문래동 가족 외식 고기집 |
| q9 | 조건형 | 문래동 가성비 고깃집 |
| q10 | 조건형 | 문래역 단체 예약 되는 식당 |

**확인 포인트**
- 메뉴형 상위 분류 = "고깃집" (삼겹살·목살 공통)
- 지역 일반형 q2는 고깃집 특성상 "점심" 대신 "저녁"

## 2. 달빛제과 (베이커리 카페)

| 입력 | 값 |
| --- | --- |
| 지역 | 서울 성동구 성수동2가 → 동: **성수동** |
| 가까운 역 | 없음 |
| 대표 메뉴 | 소금빵 (1개) |

**입력 조건 처리**
- "성수동2가" → 손님은 "성수동"으로 물음 → 동 이름에서 "1가·2가·3가" 제거
- 역 없음 → 10개 모두 동 이름 사용
- 메뉴 1개 → 메뉴형 = 대표 메뉴 1개 + 상위 분류 1개 + 상위 분류 다른 표현 1개

**상황·조건 선택**
- 상황: 데이트 / 친구 모임 / 혼밥·1인 → 카페는 혼자 오는 손님도 많음
- 조건: 가성비(고정) / 분위기 좋은

| id | 유형 | 질문 |
| --- | --- | --- |
| q1 | 지역 일반형 | 성수동 맛집 추천해줘 |
| q2 | 지역 일반형 | 성수동 점심 먹고 갈 카페 |
| q3 | 메뉴형 | 성수동 소금빵 맛집 |
| q4 | 메뉴형 | 성수동 빵집 추천해줘 |
| q5 | 메뉴형 | 성수동 베이커리 카페 어디가 좋아? |
| q6 | 상황형 | 성수동 데이트하기 좋은 카페 |
| q7 | 상황형 | 성수동 친구랑 갈 만한 빵집 |
| q8 | 상황형 | 성수동 혼자 가기 좋은 카페 |
| q9 | 조건형 | 성수동 가성비 좋은 빵집 |
| q10 | 조건형 | 성수동 분위기 좋은 베이커리 |

**확인 포인트**
- "성수동2가"가 질문에 그대로 들어가면 안 됨 → 코드 검사에서 동 이름은 "성수동" 기준
- 상황 목록에 "카페 작업·공부"가 없음 → 카페 업종 비중이 크면 목록에 추가 검토 `[결정 필요]`

## 3. 부산할매국밥 연산점 (국밥)

| 입력 | 값 |
| --- | --- |
| 상호 | 부산할매국밥 연산점 → 비교용: **부산할매국밥** |
| 지역 | 부산 연제구 연산동 → 동: 연산동 |
| 가까운 역 | 연산역 |
| 대표 메뉴 | 돼지국밥, 순대국밥 |

**입력 조건 처리**
- 지점명 "연산점" → 언급 판정에서 "부산할매국밥"만 있어도 언급 (5-1 표기 통일)
- 다른 지역의 "부산할매국밥" (예: 서면점)이 답변에 나오면 → 미언급 처리 대상, AI 판정에서 지역으로 구분
- 서울 외 지역 → 질문에 "부산"을 붙일지: 동 이름만으로 지역이 모호할 때만 붙임 (연산동은 부산에만 있어 생략)

**상황·조건 선택**
- 상황: 혼밥·1인 / 늦은 밤 / 가족 외식
- 조건: 가성비(고정) / 주차

| id | 유형 | 질문 |
| --- | --- | --- |
| q1 | 지역 일반형 | 연산동 맛집 추천해줘 |
| q2 | 지역 일반형 | 연산역 근처 점심 뭐 먹지? |
| q3 | 메뉴형 | 연산동 돼지국밥 맛집 |
| q4 | 메뉴형 | 연산역 순대국밥 잘하는 곳 |
| q5 | 메뉴형 | 연산동 국밥집 추천해줘 |
| q6 | 상황형 | 연산역 혼밥하기 좋은 식당 |
| q7 | 상황형 | 연산동 늦게까지 하는 국밥집 |
| q8 | 상황형 | 연산동 부모님이랑 갈 식당 |
| q9 | 조건형 | 연산동 가성비 좋은 밥집 |
| q10 | 조건형 | 연산역 주차 되는 국밥집 |

**확인 포인트**
- 질문에 상호 일부인 "부산할매"가 들어가면 안 됨 → 코드 검사 대상
- 질문 생성 프롬프트의 "서울의 동네 식당을 찾는 손님" 문구 → "동네 식당을 찾는 손님"으로 수정 필요 (서울 외 지역 대응)

## 4. 홍매반점 (중식)

| 입력 | 값 |
| --- | --- |
| 지역 | 대전 서구 둔산동 → 동: 둔산동 |
| 가까운 역 | 정부청사역 |
| 대표 메뉴 | 짜장면, 짬뽕, 탕수육 (3개) |

**입력 조건 처리**
- 메뉴 3개 → 메뉴형 = 앞의 대표 메뉴 2개 + 상위 분류 1개, 세 번째 메뉴(탕수육)는 상황형·조건형 문장에 자연스럽게 쓸 수 있으면 사용
- "둔산동"은 대전에만 있어 "대전" 생략

**상황·조건 선택**
- 상황: 회식·단체 / 가족 외식 / 아이와 함께
- 조건: 가성비(고정) / 포장

| id | 유형 | 질문 |
| --- | --- | --- |
| q1 | 지역 일반형 | 둔산동 맛집 추천해줘 |
| q2 | 지역 일반형 | 정부청사역 근처 점심 어디 갈까? |
| q3 | 메뉴형 | 둔산동 짜장면 맛집 |
| q4 | 메뉴형 | 둔산동 짬뽕 잘하는 집 |
| q5 | 메뉴형 | 둔산동 중국집 추천해줘 |
| q6 | 상황형 | 둔산동 회식하기 좋은 중식당 |
| q7 | 상황형 | 둔산동 가족이랑 탕수육 먹을 곳 |
| q8 | 상황형 | 정부청사역 아이랑 가기 좋은 식당 |
| q9 | 조건형 | 둔산동 가성비 중국집 |
| q10 | 조건형 | 둔산동 탕수육 포장 맛집 |

**확인 포인트**
- 메뉴형 상위 분류 = "중국집" (손님 말투 기준, "중식당"보다 흔함)
- 세 번째 메뉴가 q7·q10에 들어감 → 메뉴형 개수(3개)는 그대로

## 5. 파스타공방 (양식)

| 입력 | 값 |
| --- | --- |
| 지역 | 서울 마포구 연남동 → 동: 연남동 |
| 가까운 역 | 홍대입구역 |
| 대표 메뉴 | 생면 파스타, 리조또 |

**상황·조건 선택**
- 상황: 데이트 / 친구 모임 / 혼밥·1인
- 조건: 가성비(고정) / 분위기 좋은

| id | 유형 | 질문 |
| --- | --- | --- |
| q1 | 지역 일반형 | 연남동 맛집 추천해줘 |
| q2 | 지역 일반형 | 홍대입구역 근처 저녁 어디가 좋아? |
| q3 | 메뉴형 | 연남동 생면 파스타 맛집 |
| q4 | 메뉴형 | 연남동 리조또 맛있는 곳 |
| q5 | 메뉴형 | 연남동 파스타집 추천해줘 |
| q6 | 상황형 | 연남동 데이트 코스 식당 |
| q7 | 상황형 | 홍대입구역 친구랑 가기 좋은 양식집 |
| q8 | 상황형 | 연남동 혼자 파스타 먹기 좋은 곳 |
| q9 | 조건형 | 연남동 가성비 파스타 |
| q10 | 조건형 | 연남동 분위기 좋은 레스토랑 |

**확인 포인트**
- 역 이름 "홍대입구역"은 동(연남동)과 이름이 다름 → 손님은 두 표현을 모두 씀, 둘 다 사용
- 메뉴형 상위 분류 = "파스타집" (생면 파스타·리조또를 아우르는 손님 표현)

## 이 예시의 용도

- 질문 생성 프롬프트를 고칠 때 이 5곳을 입력해 보고, 위 표와 같은 유형·규칙으로 나오는지 비교
- **실제 측정(언급률) 점검은 실존 가게로 해야 함** → 가상 가게는 AI 답변에 절대 나오지 않아 언급률이 항상 0%
  - 수요일 품질 점검 세트: 팀원 동네의 실존 식당 5곳을 업종이 겹치지 않게 골라 사용 `[작성 필요]`
