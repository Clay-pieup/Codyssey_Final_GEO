## 1. 문제 정의

### 1-1. 상황
- 정보 탐색 경로: 검색창 → 대화형 AI(ChatGPT·Claude·Gemini)로 이동 중
- Gartner 예측(2024): 2026년까지 기존 검색엔진 이용량 25% 감소
- AI 답변 = 링크 목록이 아닌 요약 한 덩어리 → 언급되지 않은 브랜드는 노출 기회 없음

### 1-2. 문제
- 중소 브랜드: AI가 자사를 언급하는지 확인할 수단 없음
- 직접 확인 시: AI 여러 개 × 질문 여러 개 × 반복 질의 → 시간 소모
- 같은 질문에도 답이 매번 달라 한두 번 확인으로는 판단 불가

### 1-3. 해결 방향
- 브랜드 정보 입력 → 질문 생성·질의·분석 자동 처리
- 결과: 언급 여부·언급 순서·경쟁사 비교 + 개선 제안
- 진단 직후 결과 메일 자동 발송

## 2. 타겟 사용자

### 2-1. 1차 타겟: 외식업 사장님
- 선정 이유: 업종 고정 → 질문 세트를 외식업 맞춤으로 설계 → 진단 품질 안정
- 소비자 질문 패턴 명확: "OO동 점심 맛집", "OO역 근처 회식 장소" → 지역 + 메뉴 + 상황
- 업종 외 확장: 1차 범위 밖

### 2-2. 사용자 특징
- 매장 운영과 홍보를 직접 병행 → 마케팅에 쓸 시간·인력 부족
- 개발·데이터 분석 지식 없음 → 입력은 상호·지역·메뉴만, 결과는 읽기 쉬운 리포트
- 배달앱·지도앱 리뷰는 관리하지만 AI 답변 노출은 확인 방법 모름

### 2-3. 테스터 확보
- 목표 7~8명 (필수 5명 + 이탈 대비)
- 모집 경로: 당근 광고 → 매장 지역 기반 외식업 사장님 직접 모집
- 수집 항목: 이메일(결과 발송용) → 수집 동의 필수

## 3. AI 활용 방식

| 기능 | AI 방식 | 입력 → 출력 |
| --- | --- | --- |
| 질문 생성 | 생성형 AI | 상호·지역·대표 메뉴 → 실제 손님이 물을 법한 질문 10개 |
| 답변 수집 | 생성형 AI | 질문 1개 × 3회 반복 → 답변 원문 |
| 답변 분석 | 생성형 AI | 답변 원문 → 언급 여부·순서·묘사를 정해진 형식(JSON)으로 추출 |
| 추가 질의 판단 | **AI Agent** | 분석 결과 → "언급 부족 시 경쟁사·세부 질문 추가 여부와 내용" 스스로 결정 |
| 개선 제안 | 생성형 AI | 분석 결과 → 실행 가능한 개선안 3개 |

### 3-1. Agent 범위
- 판단 대상: 추가 질문을 할지, 어떤 질문을 할지
- 상한: 추가 질의 최대 `[결정 필요]`회 → API 비용·응답 시간 통제
- 근거 기록: 왜 추가 질문을 했는지 결과에 남김 → 인터뷰 설명 자료

### 3-2. 측정 신뢰도 장치
- 같은 질문 3회 반복 → 평균값 사용
- 결과 화면에 "AI가 생성한 추정치" 표시
- 웹 검색 옵션 사용 여부 `[결정 필요]` → 사람이 앱에서 받는 답과의 차이 축소 목적, 비용 확인 후 결정

## 4. 기술적 접근

### 4-1. 구성
- 화면 → 서버(Python) → Gemini API
- 진단 완료 → 서버가 Make 웹훅 호출 → Make가 결과 메일 즉시 발송
- AI 호출은 파일 1개에 모음 + 결과 형식 통일 → 2차에 ChatGPT·Claude 추가 시 파일만 추가

### 4-2. 필수 기술 요소 (2개)

| 기술 요소 | 이 서비스에서 |
| --- | --- |
| AI Agent | 언급 부족 시 추가 질의 여부·내용을 AI가 판단 |
| 자동화 워크플로우 | Make: 진단 완료 신호 → 결과 메일 즉시 발송 |

### 4-3. 배포·저장
- 배포: Vercel → 화면과 서버(Python)를 한 곳에서 배포, push만으로 재배포
- 화면 기술: `[결정 필요]` 화면·배포 담당 제안
- 진단 결과 저장: Make → 구글 시트 기록 (메일 발송과 같은 시나리오에 단계 1개 추가)
  - Vercel은 서버에 파일을 계속 남기지 못함 → 외부 저장 필요
  - 코드 추가 없이 저장 → 팀 전원이 시트로 피드백 분석·발표 통계 작성
  - 시트 2개 분리: `진단결과`(상호·지역·질문·답변·분석, 이메일 없음) / `연락처`(이메일·동의 시각)

### 4-4. AI 윤리·개인정보
- 결과 리포트·메일에 AI 생성 콘텐츠·추정치 명시
- 이메일 수집 전 동의 필수 (항목·목적·보관 기간·거부 권리 고지)
- 보관 기간: 프로젝트 종료 후 30일 → 2026-11-24 `연락처` 시트·Make 실행 기록·발송 메일함에서 파기
- `연락처` 시트 공유 범위: 팀원 3명만
