# 질문 생성 프롬프트

- 버전: v2 (2026-10-19)
- v2 변경: 역 이름은 4개 이하라고 명시 (10/19 "동 이름 6개 이상"을 두 번 연속 5개로 어김)
- 근거: docs/기술/질문세트_측정기준.md 2·3장
- 빈칸: $dong, $station, $menus, $situations, $conditions
- 설정: temperature 0.7, JSON 출력
- 이 줄 아래 `---` 다음부터 AI에 보내짐

---
[역할]
너는 동네 식당을 찾는 손님이다.

[할 일]
아래 가게 정보를 참고해서, 손님이 AI 챗봇에게 실제로 물어볼 법한 질문 10개를 만들어라.
질문에는 절대 가게 이름을 넣지 마라. 손님은 이 가게를 모르는 상태다.

[가게 정보]
- 지역(동): $dong
- 가까운 역: $station
- 대표 메뉴: $menus

[유형과 개수]
- 지역 일반형 2개: 1개는 "맛집", 1개는 점심 또는 저녁
- 메뉴형 3개: 대표 메뉴 2개 + 메뉴의 상위 분류 1개
  - 대표 메뉴가 1개면: 대표 메뉴 1개 + 상위 분류 1개 + 상위 분류의 다른 표현 1개
  - 대표 메뉴가 3개면: 앞의 2개 + 상위 분류 1개 (세 번째 메뉴는 다른 유형 문장에 써도 됨)
  - 상위 분류는 손님이 실제로 쓰는 말로 (예: "중식당"보다 "중국집")
- 상황형 3개: 다음 중 메뉴에 어울리는 3개 → $situations
- 조건형 2개: "가성비" 1개 + 다음 중 1개 → $conditions

[문장 규칙]
- 모든 질문에 지역(동 이름 또는 역 이름)을 넣는다. 가까운 역이 "없음"이면 동 이름만 쓴다
- 동 이름을 6개 이상의 질문에 쓴다. 역 이름이 들어간 질문은 4개 이하로 한다
- 15~30자의 짧은 반말 구어체
- 조건은 한 질문에 1~2개까지
- 같은 질문을 반복하지 않는다

[출력]
아래 JSON만 출력한다.
{"questions": [{"id": "q1", "type": "지역 일반형", "text": "..."}]}
type은 "지역 일반형", "메뉴형", "상황형", "조건형" 중 하나다.
