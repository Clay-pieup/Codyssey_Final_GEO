# 답변 분석 프롬프트

- 버전: v3 (2026-11-26)
- 근거: docs/기술/질문세트_측정기준.md 5·6장
- 빈칸: $store_name, $dong, $menus, $question, $answers
- 설정: temperature 0, JSON 출력
- v3 변경: AI 답변이 우리 가게에 대해 말한 구체 정보(위치·메뉴·가격·영업시간 등)를 facts로 뽑고, 사장님 입력(동·대표 메뉴)과 비교한 결과(check)를 함께 받음 → 오정보 점검. 분석 호출 수는 그대로
- v2 변경: 답변 1개씩이 아니라 같은 질문의 반복 답변(보통 3개)을 한 번에 분석 → 분석 호출 30회 → 10회
- 이 줄 아래 `---` 다음부터 AI에 보내짐

---
[할 일]
아래는 같은 손님 질문에 대한 AI 챗봇의 답변 여러 개다.
각 답변에 "$store_name"($dong)이 나오는지 답변마다 따로 분석해서 JSON으로만 답하라.

[사장님이 입력한 가게 정보]
- 상호: $store_name
- 지역(동): $dong
- 대표 메뉴: $menus

[판정 규칙]
- 띄어쓰기, 돈가스/돈까스 표기, 지점명이 달라도 같은 가게면 언급으로 본다
- 다른 지역의 같은 이름 가게는 언급이 아니다
- "행복한 돈까스"처럼 상호가 아닌 일반 표현은 언급이 아니다
- 출처 링크가 아니라 본문 기준으로 판단한다

[답변마다 추출할 것]
- no: 답변 번호 (아래 [답변 1], [답변 2]의 숫자)
- mentioned: 언급 여부 (true/false)
- is_list: 답변이 여러 가게를 나열하는 형태인지 (true/false)
- rank: 나열 형태일 때 이 가게가 처음 나온 순서 (1부터, 아니면 null)
- description: 이 가게를 설명한 문구 원문 (50자 이내, 없으면 null)
- sentiment: "긍정" / "중립" / "부정" (언급 없으면 null)
- other_stores: 답변에 나온 다른 가게 목록 [{"name": "...", "description": "..."}] (최대 5곳)
- facts: 답변이 이 가게에 대해 말한 구체 정보 목록 (언급 없으면 [], 최대 4개)
  - item: "위치" / "메뉴" / "가격" / "영업시간" / "기타" 중 하나 (기타: 주차·예약·휴무·좌석 등)
  - text: 답변에 적힌 내용 그대로 (40자 이내)
  - check: [사장님이 입력한 가게 정보]와 비교한 결과
    - "같음": 위치가 입력한 동과 같거나, 메뉴가 입력한 대표 메뉴와 같은 경우
    - "다름": 위치가 입력한 동이 아닌 다른 동·지역이라고 한 경우, 또는 가게 종류가 대표 메뉴와 전혀 맞지 않는 경우 (예: 대표 메뉴가 돈까스인데 "중국집"이라고 함)
    - "모름": 입력으로 맞는지 알 수 없는 경우. 가격·영업시간·기타는 항상 "모름". 대표 메뉴가 아닌 다른 메뉴도 "모름"
  - "맛있다", "분위기가 좋다" 같은 평가는 facts에 넣지 않는다 (description에 해당)
  - 답변에 없는 정보를 지어내지 않는다

[출력 형식]
{"results": [{"no": 1, "mentioned": true, "is_list": true, "rank": 2, "description": "...", "sentiment": "긍정", "other_stores": [{"name": "...", "description": "..."}], "facts": [{"item": "위치", "text": "...", "check": "같음"}]}]}

[질문]
$question

$answers
