# Codyssey_Final_GEO

> 코디세이 AI 네이티브 Final Project · 3인 팀 · 2026-10-17 ~ 2026-10-25 · 작성 중

## 1. 프로젝트 개요

외식업 사장님이 가게 정보를 넣으면, ChatGPT·Claude·Gemini 같은 대화형 AI가 그 가게를 얼마나 언급하는지 진단하고 무엇을 고치면 되는지 제안하는 **GEO(생성형 엔진 최적화) 진단 서비스**입니다.

- 1차: Gemini 하나로 처음부터 끝까지 완성
- 2차(여유가 있을 때): ChatGPT·Claude 추가
- 제출 요건 대비 현황: [제출 점검표](docs/제출_점검표.md) (제출물 6종, 평가기준 G1~G7)
- 진단 흐름 예시: [시연 페이지](https://claude.ai/artifact/NzMBnhMeMYeXshftv4vL5e) · [예시 문서](docs/서비스_진단_예시.md) (둘 다 가상 데이터)

| 역할 | 담당 업무 | 작업 브랜치 | 기여 요약 (본인 작성) | 대표 커밋·PR·문서 |

- **기여 요약은 팀원 본인이 직접 씁니다** (평가기준 G6). 3~5줄로 무엇을 했고 어떤 결정을 했는지 적어 팀장에게 전달 → 팀장이 이 표에 옮깁니다.
- 대표 커밋·PR·문서 링크는 각자 2~3개씩 고릅니다.

## 3. 브랜치 규칙

```
main ← 제출·배포되는 완성본 (직접 커밋 불가)
 ├─ feature/pm-backend  (팀장)
 ├─ feature/ai          (AI 담당)
 └─ feature/frontend    (화면·배포 담당)
```

1. 각자 자기 브랜치에서만 작업하고 커밋합니다.
2. 작업 단위가 끝나면 Pull Request(PR)로 `main`에 합치기를 요청합니다.
3. 팀원 PR은 **팀장 승인이 있어야만** 합쳐집니다. 저장소 설정(룰셋 + CODEOWNERS)으로 강제되어 있습니다. 팀장 PR은 예외입니다.
4. 커밋 메시지는 "무엇을 왜 바꿨는지" 한 줄로 씁니다.
5. API 키는 코드에 쓰지 않습니다. `.env` 파일에 넣고, 이 파일은 `.gitignore`로 저장소에 올라가지 않게 막아 두었습니다.
