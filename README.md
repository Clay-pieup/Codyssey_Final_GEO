# Codyssey_Final_GEO

> 코디세이 AI 네이티브 Final Project · 3인 팀 · 작성 중인 초안입니다.

## 1. 프로젝트 개요

브랜드 이름만 넣으면, ChatGPT·Claude·Gemini 같은 대화형 AI가 그 브랜드를 얼마나 언급하는지 진단하고 무엇을 고치면 되는지 제안하는 **GEO(생성형 엔진 최적화) 진단 서비스**입니다.

- 1차: Gemini 하나로 처음부터 끝까지 완성
- 2차(여유가 있을 때): ChatGPT·Claude 추가

## 2. 팀원 및 역할

| 역할 | 담당 업무 | 작업 브랜치 |
| --- | --- | --- |
| 팀장 | 기획·명세, 서버(백엔드), 사용자 테스트, 발표 총괄 | `feature/pm-backend` |
| AI 담당 | 질문 생성, AI 질의·답변 분석, 개선 제안, 프롬프트 관리 | `feature/ai` |
| 화면·배포 담당 | 화면(프론트엔드), 외부 배포, Make 자동화 | `feature/frontend` |

## 3. 브랜치 규칙

```
main ← 제출·배포되는 완성본 (직접 커밋하지 않음)
 ├─ feature/pm-backend  (팀장)
 ├─ feature/ai          (AI 담당)
 └─ feature/frontend    (화면·배포 담당)
```

1. 각자 자기 브랜치에서만 작업하고 커밋합니다.
2. 작업 단위가 끝나면 Pull Request(PR)로 `main`에 합치기를 요청합니다.
3. PR은 다른 팀원 1명 이상이 확인한 뒤 합칩니다. `main`에 합쳐지면 바로 배포본에 반영되기 때문입니다.
4. 커밋 메시지는 "무엇을 왜 바꿨는지" 한 줄로 씁니다.
5. API 키는 코드에 쓰지 않습니다. `.env` 파일에 넣고, 이 파일은 `.gitignore`로 저장소에 올라가지 않게 막아 두었습니다.
